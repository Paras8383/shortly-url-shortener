Build a modern, clean, responsive frontend for a URL shortener web application.

### Tech stack

* React
* Vite
* JavaScript
* CSS or Tailwind CSS
* No backend for now
* The frontend should be structured so I can easily connect it to an AWS API Gateway endpoint later.

### Main purpose

The application allows a user to enter a long URL and generate a shortened URL.

### UI

Create a polished landing page with:

1. A simple navigation/header

   * App name: "Shortly"
   * Minimal navigation
   * A clean modern appearance

2. Hero section

   * Large heading: "Shorten your links."
   * Supporting text explaining that users can turn long URLs into short, shareable links.
   * A prominent URL input field.
   * A "Shorten URL" button.

3. URL shortening form

   * Input placeholder: "Paste your long URL here..."
   * Validate that the entered value is a valid URL.
   * Disable the button while a request is being processed.
   * Show a loading state.
   * Display a useful error message if the URL is invalid or the API request fails.

4. Result section
   After a successful request, display:

   * The generated short URL
   * A "Copy" button
   * A visual confirmation when the URL has been copied
   * A "Shorten another URL" option

5. How it works section
   Explain the process in three simple steps:

   * Paste your URL
   * Generate your short link
   * Share it anywhere

6. Footer

   * Simple and minimal
   * Include "Built with AWS" as a placeholder

### Design

* Modern SaaS-style interface
* Clean typography
* Spacious layout
* Rounded cards and buttons
* Subtle shadows
* Responsive on desktop, tablet, and mobile
* Avoid excessive animations
* Use tasteful hover and transition effects
* Make accessibility a priority
* Good contrast and readable text

### AWS API integration preparation

Do NOT create the AWS backend.

Create a separate API utility/module so the backend endpoint can easily be changed later.

Use an environment variable such as:

VITE_API_URL

The frontend should eventually send:

POST ${VITE_API_URL}/shorten

with:

{
"url": "https://example.com/very/long/url"
}

Expect a response like:

{
"shortUrl": "https://example.com/aB72x"
}

For now, if VITE_API_URL is not configured, use mock data so the frontend can still be demonstrated and tested locally.

Structure the code cleanly so I can later replace the mock API call with my AWS API Gateway endpoint without changing the UI.

### Important

* Do not add authentication.
* Do not add a database.
* Do not use Firebase, Supabase, or another backend service.
* Do not deploy anything automatically.
* Keep the project simple and beginner-friendly.
* Make sure the application actually runs with `npm run dev`.
* Include a clear README explaining how to run the frontend locally and where to put the VITE_API_URL environment variable.
